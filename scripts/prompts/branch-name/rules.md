# 브랜치 이름 규칙

- 출력은 **한 줄**만. 설명·코드펜스·따옴표 금지.
- 형식: `{type}/{short-kebab-slug}`
- **type**은 아래만 허용: `feat` | `fix` | `chore` | `docs` | `test` | `dev`
- slug는 소문자·숫자·하이픈만. 공백·언더스코어·한글·경로(`/` 추가) 금지.
- 짧고 변경 요지를 담을 것 (대략 3~6 단어 분량 kebab).
- 커밋 prefix 규칙과 톤을 맞출 것 (`feat`/`fix`/`chore`/`docs`/`test`/`dev`).
- 사용자가 이미 이름을 준 경우 이 규칙을 무시하고 사용자 값을 쓴다 (스크립트가 처리).
