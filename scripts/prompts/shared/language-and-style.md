# 언어 및 문체

- **언어:** 반드시 한국어로 작성합니다. 제목·본문 모두 한국어로 쓰며, 기존 `git log`가 영어여도 영어로 쓰지 않습니다. (고유명사, CLI 명령어, 설정 키, 파일 경로는 원문 유지)
- **문체:** 리뷰어와 미래의 자신이 읽기 쉬운 **명확한 한국어**로 작성합니다. 채팅용 축약·단편·불완전 문장은 사용하지 않습니다.
- **제목:** 짧고 핵심만 담습니다. (커밋·PR 공통)
- **본문·bullet:** 항목마다 **완결된 문장**으로 작성합니다. 한 bullet을 읽었을 때 의미가 바로 전달되어야 합니다. 불필요한 수식어·경어체는 생략해도 됩니다.
